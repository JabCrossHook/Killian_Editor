- **ต่อจุดเข้าใช้งานให้ครบ** — เดิม 13 โมดูลถูก import ไว้เฉย ๆ ไม่มีเมนู/ปุ่ม/คีย์ลัดเรียกเลย
  ตอนนี้มีในเมนูแล้ว: ตั้งค่า AI · AI สรุปเนื้อหา · AI แนะนำชื่อเรื่อง · ศูนย์รวม (Centralize) ·
  ผังแตกสาย (Branch Tree) · ผังพื้นที่ (Floor Plan) · สมุดโน้ตด่วน · โน้ตด่วน/ดูโน้ตทั้งหมด ·
  คอมเมนต์ในฉาก · ประวัติการตัดสินใจ · จัดการสถานะฉาก · จัดการแท็บสี · สำรองเดี๋ยวนี้ ·
  สร้างโปรเจกต์จากเทมเพลต · ส่งออก .zip / .json / HTML สำหรับบล็อก
- **แก้คีย์ลัดชนกัน** — Ctrl+Shift+F เคยยิง 3 คำสั่งพร้อมกัน (โฟกัส + ค้นทั้งโปรเจกต์ + โฟกัส 2.0)
  และ Ctrl+P ยิงทั้งสั่งพิมพ์และเปิดไฟล์ด่วน · ตอนนี้: **Ctrl+Shift+F** = ค้นทั้งโปรเจกต์ ·
  **Ctrl+Shift+D** = โหมดโฟกัส · **Ctrl+Shift+O** = เปิดไฟล์ด่วน · **Ctrl+P** = สั่งพิมพ์อย่างเดียว
- **โหมดโฟกัส/เครื่องพิมพ์ดีดใช้ได้จริง** — เดิมหาบรรทัดที่พิมพ์อยู่ไม่เจอเลย (เรียก .closest() บน text node)
  ผลคือโฟกัสหรี่ทุกบรรทัดรวมบรรทัดที่กำลังเขียน และเครื่องพิมพ์ดีดไม่เลื่อนจอ
- **ส่งออก .zip ได้ไฟล์ใช้งานได้** — เดิมแปลงไบนารีเป็นข้อความก่อนเขียน (utf-8) ไฟล์เสียทุกครั้ง
- **สำรองอัตโนมัติไม่ทำรูปพัง + ทำงานจริง** — เดิมคัดลอกไฟล์ผ่านการอ่านเป็นข้อความ (รูปเสีย)
  และตั้งเวลา 24 ชม. ล้วน ๆ (โปรแกรมพกพาแทบไม่เคยเปิดค้างครบวัน) → ตอนนี้เช็ค "วันนี้สำรองหรือยัง"
  ตอนเปิดโปรเจกต์และทุกชั่วโมง
- **คอมเมนต์ไม่หายอีก** — เดิมเขียนทับลงอาร์เรย์ทั้งบทแทนแถวฉาก ทำให้คอมเมนต์หายตอนบันทึก
- **สถานะฉากที่ตั้งเองใช้ได้จริง** — โผล่ในเมนูสถานะ/แผงคุณสมบัติ/ตารางฉากแล้ว และลบแล้วบันทึกจริง
- **ส่งออก HTML สำหรับบล็อกเป็น HTML จริง** — เดิมได้ markdown ดิบ (มี # ** และ frontmatter ติดไปด้วย)
- **เปิดไฟล์ด่วนแสดง path ถูกต้อง** (เดิมขึ้น `[object Promise]`) + ข้ามโฟลเดอร์สำรอง/ถังขยะ
  และเปิดไฟล์ .json/.txt เป็นแท็บที่ **บันทึกได้** (ตรวจรูปแบบ JSON ก่อนเขียน)
- **ผังแตกสายสร้างทางเลือกได้ในตัว** — เดิมอ่านอย่างเดียวแต่ไม่มีที่ไหนเขียน choices ได้ หน้าจึงว่างตลอด
  เดินตามทางเลือก = บันทึกลงประวัติการตัดสินใจอัตโนมัติ
- **ผังพื้นที่ผูกกับข้อมูลจริง** — อ่านแผนที่/หมุดจาก maps.json และเพิ่ม "สิ่งที่เห็น/ได้ยิน/พบ" ของฉากได้
- **ความปลอดภัย/ความเป็นส่วนตัว:**
  • API key ของ AI ย้ายไปไฟล์แยก `ai-key.json` (เดิมเก็บใน project.khn.json ที่ตั้งใจให้แชร์กัน)
  • เรียก AI ผ่าน main process แล้ว (เดิมเรียกจากหน้าเว็บตรง ๆ ซึ่งติด CORS ใช้จริงไม่ได้)
  • ข้อความจากผู้ใช้ (โน้ต/คอมเมนต์/ชื่อแท็ก/ชื่อ Wiki) ไม่ใส่ลง innerHTML อีก — กันสคริปต์ฝัง
  • เอา iconify CDN ออกจาก index.html — โปรแกรมพกพาไม่ควรพึ่งเน็ตตอนเปิด
  • ค้นคำพ้อง (ส่งคำที่เลือกออกไป datamuse.com) **ปิดเป็นค่าเริ่มต้น** และรวมอยู่ในเมนูคลิกขวาเดิม
    ไม่เด้งเมนูซ้อน · ใช้ได้เฉพาะคำอังกฤษ (ไม่มีคลังคำพ้องไทย — คำไทยจะไม่ขึ้นเมนูนี้)
- **เทส:** e2e 378 → **438 checks** (เพิ่ม 60 ตัวครอบคลุมทุกข้อข้างบน) · unit test รันบน Windows ได้แล้ว
  (เดิมฮาร์ดโค้ด /tmp) · เทสซูมวัดจาก max-width แทนความกว้างจริง จึงไม่ fail บนจอแคบ
