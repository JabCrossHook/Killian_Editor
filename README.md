# Killian 2 (alpha) — โปรแกรมเขียนนิยาย/บทหนัง ยุคใหม่

สร้างใหม่ทั้งตัวบน **Electron + ProseMirror** (engine ตระกูลเดียวกับที่ Notion ใช้)
แทนที่ Killian v1 (Python/Tkinter) — โจทย์: ไว เสถียร ลื่นระดับ word processor

## ทำไมต้องเปลี่ยน
| ปัญหาใน v1 (Tkinter) | ใน Killian 2 |
|---|---|
| editor ประกอบเอง ติด ๆ ขัด ๆ | ProseMirror: rich text engine ระดับมืออาชีพ ลื่นแบบ MS Word |
| คีย์ลัดใช้ไม่ได้ตอนแป้นพิมพ์ภาษาไทย | คีย์ลัดผูกระดับ OS ผ่านเมนู → ใช้ได้ทุกภาษาแป้นพิมพ์ |
| ไม่มี Save As / Print | มีครบ: บันทึกเป็น… พิมพ์… ส่งออก PDF |
| รูปได้แค่ PNG/GIF (ไม่มี Pillow) | ทุกสกุลที่ Chromium รองรับ: PNG JPG GIF WebP SVG AVIF BMP ICO |
| Undo ไม่ย้อนรูปแบบตัวอักษร | Undo/Redo ย้อนทุกอย่างรวมรูปแบบ |
| แจก portable Python | แตก zip ดับเบิลคลิก .exe — ไม่ต้องติดตั้งอะไร offline 100% |

## ใหม่ใน alpha.57 — มุมมองบท · ตรวจข้อผิดพลาด · ส่งออก FDX/RTF/PDF ลายน้ำ

**เมนูใหม่ "บท"** รวมงานบทภาพยนตร์ไว้ที่เดียว

- **โหมดมุมมอง 5 แบบ** (แถบเครื่องมือ หรือ เมนู บท → มุมมองบท)
  - **ปกติ** หน้ากระดาษเหมือนเดิม
  - **ร่าง (Draft)** ข้อความล้วนบนพื้นว่าง เต็มความกว้าง · ตัวคั่นหน้าเป็นเส้นบาง ๆ มีเลขหน้า
  - **เรียงหน้าคู่ (Side-by-Side)** วางหน้ากระดาษจริงหลายหน้าเรียงกัน ย่อพอดีจออัตโนมัติ (สูงสุด 4 หน้า/แถว)
  - **ภาพรวม 1px / 4px ต่อตัวอักษร** เห็นรูปทรงของบททั้งเรื่องรวดเดียว
  - โหมดเรียงหน้า/ภาพรวมอ่านอย่างเดียว — **คลิกตรงไหนก็กลับไปแก้ตรงนั้นได้ทันที**
- **แสดงรูปแบบ** — เส้นฟ้าบอกขอบซ้าย-ขวาของแต่ละ element + เครื่องหมายท้ายบรรทัด (`¶` จบบล็อก · `·` ตัดบรรทัดเอง)
- **ไปที่หน้า/ฉาก `Ctrl+G`** — กรอกเลขหน้า หรือเลือกจากรายการหัวฉาก
- **ตรวจหาข้อผิดพลาดในบทอัตโนมัติ** 8 ชนิด (ตัวละครไม่มีบทพูด · บทพูดกำพร้า · วงเล็บกำพร้า/ไม่ปิด ·
  บรรทัดยาวเกิน · หัวฉากติดกัน · เนื้อบทก่อนหัวฉากแรก · บรรทัดว่างที่ไม่ควรว่าง)
  แถบสถานะบอกจำนวน (คลิกไปข้อถัดไป) · `Ctrl+Shift+U` ไล่ทีละข้อ · **ตรวจให้ก่อนส่งออกอัตโนมัติ**
- **ส่งออก Final Draft (.fdx)** — ชนิดย่อหน้าครบตามสคีมา FD + หน้าปกจากข้อมูลผลงาน
- **ส่งออก Rich Text (.rtf)** — **ภาษาไทยไม่เพี้ยน** (แปลงเป็น `\uNNNN?` ตามสเปก RTF) ·
  ระยะเยื้อง/กระดาษ/ระยะขอบตามค่าที่ตั้งไว้
- **PDF ลายน้ำรายคน** — ใส่รายชื่อผู้รับ ได้ PDF แยกไฟล์ต่อคน ลายน้ำต่างกัน → รู้ว่าบทหลุดจากสำเนาของใคร

## ใหม่ใน alpha.56 — บทภาพยนตร์ระดับใช้งานจริง + แก้บั๊ก 13 ข้อ

**รูปแบบบทมาตรฐานอุตสาหกรรม** (โมดูลบริสุทธิ์ `src/sp-format.js` · unit test 72 ข้อ)
- **ขนาดกระดาษ + ระยะขอบ** — Letter / A4 / Legal / กำหนดเอง · ค่าเริ่มต้น บน 1" ล่าง 1" ซ้าย 1.5" ขวา 1"
  ใช้ร่วมกัน **ทั้งโหมดนิยายและโหมดบทภาพยนตร์** · เปลี่ยนได้ที่ ตั้งค่า → 📐 หน้ากระดาษ
- **ระยะเยื้อง/ความกว้าง/ระยะเว้นบรรทัด ต่อ element** — วัดเป็นนิ้วจากขอบกระดาษแบบ Final Draft
  (ตัวละคร 3.7" · บทพูด 2.5" · วงเล็บ 3.1" · ทรานซิชัน 6.0")
- **สไตล์ "บนจอ" แยกจาก "ตอนพิมพ์"** — ตัวใหญ่/หนา/เอียง/ขีดเส้นใต้ ตั้งได้ทีละ element ทีละโหมด
- **กฎการตัดหน้าจริง** — แบ่งบทพูดข้ามหน้าพร้อม `(MORE)` + ทวนชื่อ + `(cont'd)` ·
  ไม่ทิ้งชื่อตัวละครค้างท้ายหน้า · **แถบสถานะบอกจำนวนหน้า**
- **ข้อความมาตรฐานแก้ได้** — `(CONTINUED)` / `CONTINUED:` / `(MORE)` / `(cont'd)`
- **หน้ารายชื่อตัวละคร (Cast of Characters)** — หน้าเดี่ยวประจำเล่ม เก็บที่ `<เล่ม>/roster.json`
  หัวเรื่องกลางหน้าขีดเส้นใต้ → รายชื่อแบบ hanging indent → Scene → Time · ไม่มีเลขหน้า
- **ข้อมูลผลงาน 11 ช่อง** — อีเมล · ติดต่อ · Screenplay By · Based On · Revisions by · โทรศัพท์ ·
  ชื่อ/ที่อยู่/โทร/อีเมลตัวแทน · Copyright by
- **ฟอนต์มาตรฐานใหม่: Courier Final Draft 12pt ทุกภาษา** ทั้งสองโหมด · กรอกขนาดเป็นพอยต์เองได้
- **ปุ่ม Tab/Enter/Shift+Tab ในบทหนังเปลี่ยนเองได้ + ปิดได้**

**บั๊กที่แก้**: SmartType กด Enter แล้ววน (ยืนยันด้วย Tab อย่างเดียว) · ปุ่มสวิตช์ต้อง "ปิด" ไม่ใช่ "พับ" ·
จับกลุ่มแท็บได้เฉพาะชื่อแผง/20% ขวาของหัวแผง · แผงจำตำแหน่งเดิมตอนเปิดกลับ · ซูมยึดกึ่งกลาง ·
แผงแคบไม่ทำให้ตัวหนังสือถูกตัดคำ · มุมมองเริ่มต้นจัดกึ่งกลาง · โหมดอ่าน/โฟกัสไม่เหลือแผงว่าง ·
แผงลอย snap ขอบ · ปุ่ม Kanban เป็น toggle · เครื่องมือใช้ได้แม้ไม่มีแท็บฉาก ·
หน้าแรก 4 คอลัมน์ขนาดนิ่ง · ค้นหาเอนทิตี้ถึงเนื้อในไฟล์

## ใหม่ใน alpha.47 — รอบแก้บั๊ก 5 ข้อ (แยกหน้าจอ + แผง)

- **แยกหน้าจอใช้ได้จริงแล้ว และแบ่งได้ไม่จำกัดช่อง** — เดิมมีสองระบบซ้อนกันในโค้ด
  ระบบที่ทำงานอยู่ได้แค่ 2 ช่อง ส่วนระบบที่แบ่งซ้อนได้ไม่มีใครเรียกเลย ตอนนี้เหลือระบบเดียว
  · ลากหัวแท็บไปวางที่ขอบช่อง = แบ่งช่องใหม่ · วางกลางช่อง = สลับเอกสารในช่องนั้น
  · มีแท็บเดียวก็แยกจอได้ (ได้ช่องว่างไว้ลากแท็บมาวาง) · ทุกช่องมีปุ่มปิดของตัวเอง
- **แผงลอยลากปรับขนาดได้แล้ว** — ที่จับมุมขวาล่างเคยถูก CSS ซ่อนไว้ตลอด
- **สัดส่วนแผงที่ปรับเองไม่โดนล้างอีก** — เดิมเปิด/ปิดแผงทีหนึ่ง 40/60 กลายเป็นแบ่งเท่ากันหมด
- **ถาดแผงที่ปิดไว้มีทั้งฝั่งซ้ายและขวา** — แผงฝั่งขวาที่ปิดไปไม่ต้องไปตามหาที่มุมซ้ายล่าง
- **แผงไม่โผล่กลับมาเอง** — กันเลย์เอาต์เสียหายจนถูกรีเซ็ตเป็นค่าตั้งต้น + กันเผลอลากแผงตอนคลิก

## ใหม่ใน alpha.46 — จัดวางหน้าจอแบบ Photoshop

ทุกพื้นที่ของหน้าต่างกลายเป็น **"แผง"** ที่จัดวางเองได้ทั้งหมด (เดิมแถบข้างตายตัวอยู่ซ้ายเสมอ)

- **ลากหัวแผงไปวางที่ไหนก็ได้** — ลากเข้าใกล้ขอบแผงอื่นจะขึ้นแถบสีบอกว่าจะไปอยู่ตรงไหน
  (ซ้าย/ขวา/บน/ล่าง) · ปล่อยตรงกลาง = **รวมเป็นแท็บ** เดียวกัน · ปล่อยนอกโปรแกรม = **ลอยอิสระ**
- **แถบเครื่องมือกับแถบสถานะก็เป็นแผง** — ย้าย/จัดใหม่ได้เหมือนกัน
- **ลากเส้นคั่นระหว่างแผง** เพื่อปรับสัดส่วน (ดับเบิลคลิก = 50%)
- **ย่อกลุ่มแท็บเป็นแถบไอคอน** (ปุ่ม « บนแถบแท็บ) เพื่อคืนพื้นที่ให้หน้ากระดาษ
- **ปิดแผงแล้วเรียกกลับได้เสมอ** — มีปุ่มค้างไว้มุมล่างซ้าย หรือเมนู มุมมอง → แผง
- การจัดวางถูกจำไว้ให้อัตโนมัติ · รีเซ็ตได้ที่ มุมมอง → แผง → รีเซ็ตการจัดวางแผงทั้งหมด

## ใหม่ใน alpha.44 — เก็บงาน 7 ฟีเจอร์ปิดท้าย
ทั้ง 7 ข้อมีโค้ดและอยู่ในเมนูตั้งแต่ alpha.40 — รอบนี้คือทำให้ **ใช้ได้จริงครบทุกมุม**

- **โหมดโฟกัส (Ctrl+Shift+D)** — ปรับ**ความจางของบรรทัดอื่น**ได้เองที่ ตั้งค่า → การเขียน ·
  แก้ Esc ที่เคยแย่งกับกล่องโต้ตอบ/โหมดอ่าน (ตอนนี้ออกทีละชั้น)
- **โหมดเครื่องพิมพ์ดีด (Ctrl+Shift+T)** — ตัวแก้ไขใน**หน้าต่างลอย**ก็เลื่อนตามบรรทัดแล้ว (เดิมทำงานเฉพาะในช่องหลัก)
- **ส่งออกเป็น HTML สำหรับบล็อก (Ctrl+Shift+B)** — เลือก**ธีม** (Medium / เรียบ / มืด) · ใส่/ไม่ใส่ชื่อบท-ชื่อฉาก ·
  **ฝังรูปลงไฟล์เดียว (base64)** ก๊อปไปวางที่ไหนก็เห็นรูป
- **สถานะฉาก** — **มีสีแล้ว** (เลือกเองได้ทุกสถานะ) เห็นสีเดียวกันทั้ง Explorer · Kanban · ตารางฉาก ·
  **นำเข้า/ส่งออกชุดสถานะเป็น .json** ย้ายข้ามโปรเจกต์ได้
- **เปิดไฟล์ด่วน (Ctrl+Shift+O)** — จำผลสแกนไว้ (เปิดซ้ำเห็นทันที) แล้วสแกนซ้ำในพื้นหลังเสมอ

- **🏷 แท็บสี (Visual Tags)** — เห็นสี/ไอคอน/รูปทรงจริงใน **Explorer · แถบตัวกรอง · Planner · Story Network**

- **📊 ศูนย์รวม** — backlinks ใช้ **Auto-link Engine** ตัวเดียวกับหน้า Wiki (รู้จักชื่อรอง, ไม่จับผิดคำ)

## ใหม่ใน alpha.4
- **แก้ "Wiki ไม่มา"** — สองสาเหตุ: (1) โปรเจกต์ที่ยังไม่เคยสร้าง entity ไม่มีโฟลเดอร์ Wiki
  → โปรแกรมซ่อนทั้งหมวดรวมทั้งปุ่มสร้าง ตอนนี้ **4 หมวดหลักแสดงเสมอ** สร้างได้ทันที
  (2) โปรเจกต์เก่าใช้ชื่อโฟลเดอร์เดิม **Bible/** → รองรับแล้วทั้ง tree และ SmartType
  รวมทั้ง Wiki ระดับเซกชัน (<เซกชัน>/Wiki หรือ /Bible) ก็แสดงในหมวดของตัวเอง
- **ถังขยะมาแล้ว** — โผล่ใน tree พร้อมจำนวน 🗑 ถังขยะ (n): คลิกรายการ →
  **กู้คืน** (ฉากกลับเข้าบทเดิมพร้อมข้อมูล JSON ครบผ่านไฟล์ sidecar · entity กลับหมวดเดิม ·
  memo กลับ Memos) หรือ **ลบถาวร** (ยืนยันก่อน)
- e2e reset fixture ใหม่ทุกครั้ง (test/fixture.js) — กันสภาพค้างจากรอบก่อนหลอกผลเทสต์

## ใหม่ใน alpha.3
- **แก้บั๊ก "กด + แล้วไม่มีอะไรเกิดขึ้น"** — โค้ดเดิมใช้ prompt() ซึ่ง Electron ไม่รองรับ
  (พังเงียบ ๆ) → เปลี่ยนเป็น dialog ของโปรแกรมเองทั้งหมด
- **Wiki มาแล้ว**: หมวดทั้งหมดโผล่ใน tree (ตัวละคร/สถานที่/สิ่งของ/ตำนาน + หมวด custom)
  · สร้าง entity ใหม่ (โครง JSON v1 ครบทุก field) · เปิดแก้เป็นแท็บ: ชื่อ, ชื่ออื่น (aliases),
  ข้อมูลจากเทมเพลต, หัวข้อเนื้อหาแบบ WYSIWYG เพิ่ม/ลบหัวข้อได้ — บันทึกแล้ว SmartType
  เห็นชื่อใหม่ทันที
- **จัดการไฟล์จาก tree (คลิกขวา)**: เปลี่ยนชื่อ/ลบ ฉาก · บท · memo · Wiki entity
  — การลบทุกอย่างย้ายไปโฟลเดอร์ Recycle ของโปรเจกต์ (กู้คืนเองได้ ไม่หายถาวร)
- เมนูคลิกขวา native จำกัดเฉพาะในตัวแก้ไข — บน tree เป็นเมนูจัดการไฟล์แทน
- แก้ SmartType อ่านชื่ออื่นผิด field (v1 ใช้ `aliases` ไม่ใช่ `aka`)

## ใหม่ใน alpha.2
- **ขึ้นบรรทัดใหม่แล้วรูปแบบตัวอักษรติดไปด้วย** (หนา/เอียง/ขีด ไม่ reset — แบบ Word)
- **คลิกขวา** = เมนูมาตรฐาน: ตัด/คัดลอก/วาง/เลือกทั้งหมด + รูปแบบตัวอักษร + แทรกรูป (native ทุกภาษาแป้นพิมพ์)
- **ค้นหา/แทนที่** (Ctrl+F): ไฮไลต์ทุกผล · Enter/Shift+Enter เดินหน้า-ถอยหลัง · แทนที่ทีละคำ/ทั้งหมด
- **SmartType**: พิมพ์ต้นชื่อ (≥2 ตัว) → เดาชื่อจาก Wiki (รวมชื่ออื่น aka) · ↑↓ เลือก · Enter/Tab ยืนยัน
- **Index/Outline**: แผงดัชนีใต้ tree — หัวข้อ (นิยาย) + หัวฉาก (บทหนัง) คลิกแล้วกระโดด
- **Memo**: โผล่ใน tree เปิดแก้เป็น WYSIWYG · ปุ่ม + สร้าง memo/บท/ฉากใหม่ได้จาก tree (เขียน JSON โครง v1 เป๊ะ)

## พัฒนาต่อ
```
npm install        # ครั้งแรก
npm test           # ทดสอบ markdown round-trip
npm run build      # bundle renderer (esbuild)
npm start          # รัน (dev)
```
Smoke test เต็มระบบ: `KILLIAN_TEST=1 KILLIAN_TEST_PROJECT=<path> npm start`
ผลอยู่ที่ /tmp/k2result.txt + ภาพ /tmp/k2.png

renderer/ ไว้ที่ resources/app/ → เปลี่ยนชื่อ electron.exe เป็น Killian2.exe
