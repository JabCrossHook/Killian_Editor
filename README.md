# Killian 2 (alpha) — โปรแกรมเขียนนิยาย/บทหนัง ยุคใหม่

สร้างใหม่ทั้งตัวบน **Electron + ProseMirror** (engine ตระกูลเดียวกับที่ Notion ใช้)
แทนที่ Killian v1 (Python/Tkinter) — โจทย์: ไว เสถียร ลื่นระดับ word processor

## ทำไมต้องเปลี่ยน
| ปัญหาใน v1 (Tkinter) | ใน Killian 2 |
|---|---|
| editor ประกอบเอง ติด ๆ ขัด ๆ | ProseMirror: rich text engine ระดับมืออาชีพ ลื่นแบบ MS Word |
| คีย์ลัดใช้ไม่ได้ตอนแป้นพิมพ์ภาษาไทย | คีย์ลัดผูกระดับ OS ผ่านเมนู → ใช้ได้ทุกภาษาแป้นพิมพ์ |
| ไม่มี Save As / Print | มีครบ: บันทึกเป็น… พิมพ์… ส่งออก PDF |
| รูปได้แค่ PNG/GIF (ไม่มี Pillow) | ทุกสกุลที่ Chromium รองรับ: PNG JPG GIF WebP SVG AVIF BMP ICO |
| Undo ไม่ย้อนรูปแบบตัวอักษร | Undo/Redo ย้อนทุกอย่างรวมรูปแบบ |
| แจก portable Python | แตก zip ดับเบิลคลิก .exe — ไม่ต้องติดตั้งอะไร offline 100% |

## สิ่งสำคัญที่สุด: **ไฟล์เข้ากับ v1 เป๊ะ**
โครงโปรเจกต์เดิมทั้งหมด (project.khn.json / section.json / draft.json / scenes.json /
Chapters/*.md frontmatter) เปิดใน Killian 2 ได้ทันที และไฟล์ที่บันทึกกลับ
เปิดใน v1 ได้เหมือนเดิม — ใช้สองตัวควบคู่ระหว่างช่วงเปลี่ยนผ่านได้เลย
(Wiki/Memo/Story Network ยังใช้ v1 ไปก่อน จนกว่าจะย้ายครบ)

## ใหม่ใน alpha.40 — รอบเก็บกวาดฟีเจอร์ชุดใหม่
ฟีเจอร์ชุดล่าสุด 19 ตัวถูก "เขียนไว้แต่ต่อไม่ครบ" — รอบนี้ต่อให้ครบและแก้ให้ทำงานจริง

- **เข้าถึงได้จริงจากเมนูแล้ว** — ตั้งค่า AI · AI สรุปเนื้อหา/แนะนำชื่อเรื่อง · ศูนย์รวม (backlinks + สถิติสด) ·
  ผังแตกสาย · ผังพื้นที่ · สมุดโน้ตด่วน · โน้ตด่วน · คอมเมนต์ในฉาก · ประวัติการตัดสินใจ ·
  จัดการสถานะฉาก · แท็บสี (Visual Tags) · สำรองเดี๋ยวนี้ · สร้างโปรเจกต์จากเทมเพลต ·
  ส่งออก .zip / .json / HTML สำหรับบล็อก
- **คีย์ลัดไม่ชนกันแล้ว** — `Ctrl+Shift+F` ค้นทั้งโปรเจกต์ · `Ctrl+Shift+D` โหมดโฟกัส ·
  `Ctrl+Shift+O` เปิดไฟล์ด่วน · `Ctrl+Shift+T` เครื่องพิมพ์ดีด · `Ctrl+P` สั่งพิมพ์
- **ที่แก้ให้ใช้ได้จริง** — โหมดโฟกัส/เครื่องพิมพ์ดีด (เดิมหาบรรทัดปัจจุบันไม่เจอ) · ส่งออก .zip
  (เดิมไฟล์เสีย) · สำรองอัตโนมัติ (เดิมรูปพัง + แทบไม่เคยทำงาน) · คอมเมนต์ (เดิมหายตอนบันทึก) ·
  สถานะฉากที่ตั้งเอง (เดิมไม่โผล่ที่ไหน) · ส่งออกบล็อก (เดิมได้ markdown ดิบ)
- **ปลอดภัยขึ้น** — API key แยกไฟล์ `ai-key.json` ไม่ปนใน project.khn.json ที่แชร์กัน ·
  ข้อความผู้ใช้ไม่ลง innerHTML · เอา CDN ออกจากหน้าโปรแกรม (พกพา/ออฟไลน์ 100% ตามเดิม) ·
  ค้นคำพ้อง (ส่งข้อความออกเน็ต) ปิดเป็นค่าเริ่มต้น
- เทสเพิ่มเป็น **438 checks**

## Roadmap
1. ต้นไม้ฉาก: ลากจัดลำดับ (corkboard drag)
2. แผงสถิติเชิงลึก (คำเฉลี่ย/ฉาก · ความคืบหน้ารายสถานะ)
3. Build อัตโนมัติ (electron-builder) → installer + code signing + Linux

## พัฒนาต่อ
```
npm install        # ครั้งแรก
npm test           # ทดสอบ markdown round-trip
npm run build      # bundle renderer (esbuild)
npm start          # รัน (dev)
```
Smoke test เต็มระบบ: `KILLIAN_TEST=1 KILLIAN_TEST_PROJECT=<path> npm start`
ผลอยู่ที่ /tmp/k2result.txt + ภาพ /tmp/k2.png

## ประกอบ portable Windows เอง

แตก → ลบ resources/default_app.asar → วาง main.js, preload.js, package.json,
renderer/ ไว้ที่ resources/app/ → เปลี่ยนชื่อ electron.exe เป็น Killian2.exe
